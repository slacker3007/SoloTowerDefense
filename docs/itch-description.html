Solo Tower Defense is a cozy fantasy tower defense about building from one humble barracks into a layered defense that can survive 50 escalating waves.

How to play

  1. Start with the Blue Barracks selected, then use action slot 1 to place a Basic Tower.
  2. Click or tap a buildable tile beside the path. A builder will run out and construct the tower.
  3. Select towers to upgrade, sell, or convert them into specialized elemental roles.
  4. Use Settings for keybinds, audio volume, HUD scale, and accessibility options.

Speed control

Use the HUD speed button or your speed keybind to cycle x1 / x2 / x3.

Tip: mix slows, splash, chain, and high-damage towers. Boss waves punish one-dimensional defenses.
