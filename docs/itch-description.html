Tiny Tower Defense is a punchy tower defense where you select your barracks, craft your first towers, and upgrade basics to survive onslaughts. Can you hold out for 50 waves?

How to play

  1. 1: select the Blue Barracks.
  2. Q: open the Build menu, then press Q again to start placing a Basic Tower.
  3. Click a tile to place it. Select a tower to open its upgrade options.

Speed control

Use the top bar to cycle x1 / x2 / x3 for the game speed.

Tip: start small early, then funnel your gold into upgrades as soon as you can.
